## Original Core Ideas

1. Provide both a spreadsheet-style schedule and a calendar view.
2. Visualize room status like an operations dashboard.
3. Show staffing and newborn volume together to support daily decisions.
4. Use field-friendly terminology in the UI.

The app has since moved beyond these notes.
Use the active docs for detailed rules and current behavior.
